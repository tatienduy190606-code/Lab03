# Lab03_OOPAdvanced - Lập trình .NET IT3212

## Nội dung
Bài làm gồm bài 1-10 của Lab 3:
1. Kế thừa Nguoi - SinhVien
2. Ghi đè phương thức MoTa()
3. Lớp trừu tượng NguoiHoc và tính học phí
4. Interface IValidatable, IPrintable
5. Danh sách đa hình
6. Hệ thống nhân viên
7. Quản lý phương tiện
8. Quản lý tài liệu thư viện
9. Hệ thống thanh toán
10. Nâng cấp quản lý sinh viên

## Cách chạy
- Mở file `Lab03_OOPAdvanced.csproj` bằng Visual Studio 2022.
- Chọn Build -> Build Solution.
- Nhấn Ctrl+F5 để chạy.
- Dự án sử dụng .NET 8.0.

## Dữ liệu thử
Chương trình đã tích hợp sẵn dữ liệu mẫu trong `Program.cs`.

## Lưu ý
Các công thức chi phí/lương ở bài 6 và 7 được chọn làm dữ liệu minh họa vì đề bài chỉ yêu cầu thiết kế và tính toán đa hình, không cung cấp công thức cụ thể.
